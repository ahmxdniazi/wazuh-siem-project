## How to Add Screenshots

1. Take your screenshot from the Wazuh Dashboard or VM
2. Name it following the convention above (e.g., `screenshot-01-ubuntu-vm.png`)
3. Place it in this `/screenshots` folder
4. Screenshots are automatically referenced in the main README

## Screenshot Tips

- Use PNG format for best quality
- Recommended resolution: 1920×1080 or higher
- Crop to relevant UI elements
- Blur or redact sensitive credentials before uploading
